Party · HP & conditions

Quick answers. Live is for during the game: everything there reaches the stream in a few seconds. Setup is for building the stream: changes there need Publish to stream and take about a minute.

During a session
Start-of-session checklist
  1. Open this page in Live mode. The dot at the top left should be green ("Connected").
  2. Players open their camera link (the card they were sent) and type the group password.
  3. Check each "… Cam" in OBS shows the right person. Cameras move into place by themselves.
  4. Battle mode off to start.
Start a fight (show HP bars)
Press ⚔ Battle mode so it turns red. HP bars and conditions appear on stream in a few seconds. Press it again after the fight. The battle map screen shows HP bars on its own (the green 🗺 Map HP bars switch), even when battle mode is off.
Change someone's HP
  • Normally HP follows the player's D&D Beyond sheet by itself. Nothing to do.
  • To change it yourself: tap −10 −5 −1 or +1 +5 +10, or type a number and press Damage / Heal / Temp HP. Enter = Damage.
  • Once you change it here, that character is on Manual HP (their sheet is ignored). Tap Use sheet HP to undo.
Add or remove a condition
Tap ＋ Condition on the character, then tap the condition. Tap it again (or its chip with ✕) to remove it. It animates on and off on stream. Exhaustion goes up one level per tap (1–6, then off). Conditions marked · sheet come from the player's D&D Beyond sheet; clear those on the sheet. They only show on stream while HP bars show.
Show a conversation between two characters
  1. In Conversation, tap the first character (L), then the second (R). ⇄ Swap flips sides.
  2. Press Apply to conversation scene. The tiles marked ON AIR are what's showing.
  3. Switch OBS to your Conversation scene. Their cameras move into the two windows by themselves.
A player's camera is black
Their character animation shows instead, so the stream still looks fine. Ask them to open their camera link again; it reconnects to the same spot by itself. You don't need to change anything in OBS.
The dot at the top is red
  • "Enter the relay key": type the relay key in the box there and press Save. Do it once per computer.
  • "Can't reach the relay": check the internet connection, then reload the page.
Setting up (Setup mode)
Add a new character
Setup → Party → bottom of the page. Paste their D&D Beyond link (sheet set to Public) and press Import character. Everything fills in. Press Publish to stream. Then make their camera in OBS: a Browser Source named "Name Cam" with their VDO.Ninja link.
A player is away for the session
Setup → Party → their card → untick Camera window (their window disappears and everyone else re-arranges), or tick Cover camera with loop to show their animated character in their window. Publish.
Change the scrolling bar messages
Setup → Scrolling bar. Edit, add or reorder messages, then Publish.
Publishing for the first time (GitHub key)
Setup → GitHub key (top right) and follow the steps in the box. Only needed once per computer. Live mode never needs it.
OBS: cameras line up by themselves
  1. OBS → Tools → WebSocket Server Settings → tick Enable, copy the password.
  2. Every top-layer overlay link ends with &obs=YOURPASSWORD.
  3. Camera sources are named exactly Trey Cam, Darius Cam, GM Cam… and added to each scene as Existing sources.
  4. Not working? Add &obsdebug=1 to the overlay link. A box in the corner says what's wrong.
OBS scene control (see and switch scenes from Live)
  1. Setup → Show & GM → OBS link → Copy link.
  2. In OBS add a Browser Source called OBS Link to any scene, paste the link and replace OBS_PASSWORD with the OBS WebSocket password.
  3. Untick “Shutdown source when not visible”. You can hide it with the eye icon; it keeps working.
  4. Live mode now shows On stream now and a button for every scene. Tap a scene twice to switch. The Stream Deck still works; the panel follows whatever is on stream.
  5. Says “No word from OBS”? OBS is closed, or the OBS Link source was removed or has the wrong password (add &debug=1 to its link to see why).
Camera links (VDO.Ninja)
Each player has a permanent join link (on their card) and each "… Cam" source has a permanent view link ending in #p=PASSWORD. Set them once and never change them. Full details are in Reditus_VDO_Ninja_Guide.pdf.

Connect GitHub (one time)

Publishing saves data.js into your reditus-overlay repo. That needs a GitHub key, which stays in this browser only.

  1. Open github.com → New fine-grained token.
  2. Name it Reditus control panel and set an expiry you're comfortable with.
  3. Under Repository access choose Only select repositories → reditus-overlay.
  4. Under Permissions → Repository → Contents, choose Read and write.
  5. Click Generate token, copy it, and paste it below.
