Connect GitHub (one time)

Publishing saves data.js into your reditus-overlay repo. That needs a GitHub key, which stays in this browser only.

  1. Open github.com → New fine-grained token.
  2. Name it Reditus control panel and set an expiry you're comfortable with.
  3. Under Repository access choose Only select repositories → reditus-overlay.
  4. Under Permissions → Repository → Contents, choose Read and write.
  5. Click Generate token, copy it, and paste it below.
